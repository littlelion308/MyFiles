# MyFiles
This repository consist of (mostly) currently used configuration Files for my personal System

## Vim
The colorscheme is set to slate, although morning is also good.
There are some shortcut-commands, mappings and autocmd(s) configured
The following plugins are useful:
- dhruvasagar/vim-table-mode: work with (markdown) tables
- easymotion/vim-easymotion: move though text more easily
- junegunn/goyo.vim: remove the interface
- junegunn/limelight.vim: only highlight one Line of Code
- neoclide/coc.nvim: basic Code completion
- tpope/vim-commentary: comment stuff
- tpope/vim-fugitive: work with git
- tpope/vim-surround: work with brackets/Quotations
- vimwiki/vimwiki: a personal wiki
